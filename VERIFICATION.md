## 6. Webhook signature enforcement

The endpoint rejects anything not signed with the app secret:

```
unsigned POST                        -> HTTP 401  {"success":false,"error":"Invalid signature"}
forged signature (sha256=000...0)    -> HTTP 401  {"success":false,"error":"Invalid signature"}
correctly signed POST                -> HTTP 200  {"success":true}, row written, status PROCESSED
```

Rejected attempts are recorded as `OperationalEvent` warnings rather than failing
silently, so a misconfigured secret is visible.
